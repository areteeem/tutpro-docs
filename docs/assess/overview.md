# Overview

TutPro Assess is the suite’s assessment authoring and completion app. Teachers create assessments, share them with a short code or as a Teacher assignment, and review responses through the supported grading flow.

## Teacher flow

1. Open [TutPro Assess](https://assess.tutpro.org) and sign in with your TutPro account.
2. Open the assessment library and choose to create an assessment.
3. Add a title and questions. Use the question editor to choose a supported question type, enter the prompt and answer settings, and preview the learner view.
4. Save the assessment. Open it from the library when you want to edit it.
5. Share it with a student or publish an assignment from Teacher.

## Student flow

Students can open an assigned assessment from Student or use the teacher-provided join code. Normalize the code to uppercase if typing it manually. Complete the questions and use **Check answer** where available before moving to the next question. Submit when finished.

## Results and assignments

When connected to Teacher assignments, Assess uses the shared TutPro student identity and assignment history. Keep an assessment assignment distinct from an uploaded file or ordinary web link. Review the target student, due date, and availability before sharing.
