# Question types

Choose **Add question** in the builder and select the task that best matches what the learner needs to do. The current quick-add menu contains the following response types:

## Learner response types

- **Short response** — a short text answer.
- **Long response** — a longer written answer.
- **Choose one** — select one correct option.
- **Choose many** — select every applicable option.
- **Grid single choice** — select one option in a row-and-column grid.
- **Grid multiple choice** — select multiple options in a grid.
- **Select one** — choose from a searchable selection control.
- **Confidence rating** — choose a rating from configured options.
- **Number** — enter a numeric response.
- **Date** — enter a date.
- **Yes or no** — choose between two responses.
- **Conjugate a verb** — complete the configured verb forms.
- **Fill the blank** — enter an expected word or phrase.
- **Cloze text** — complete one or more gaps in a passage.
- **Dropdown cloze** — choose an answer for each gap from a dropdown.
- **Word-bank cloze** — fill gaps using choices from a word bank.
- **Order the words** — arrange items into the correct sequence.
- **Match pairs** — connect related items across two columns.
- **Categorize words** — sort items into named groups.
- **Correct a sentence** — edit a sentence to fix its configured error.
- **Highlight words** — select the requested words in a passage.
- **Vocabulary table** — enter related answers into a structured table.

## Content and layout blocks

These items help organize or explain an assessment; they are not standalone learner response questions:

- **Context group** — present a shared passage or context with related questions.
- **Section heading** — add a visual heading between questions.
- **Instructions** — insert explanatory text for the learner.

## Additional supported type

**Translation** is supported by the assessment data format and student player, but it is not currently shown in the builder’s quick-add menu. Existing assessments and compatible imported schemas can still contain it.
