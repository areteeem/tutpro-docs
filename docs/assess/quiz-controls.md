# Quiz controls

Select the quiz and review the Teacher Controls panel before publishing. Available controls include the passing percentage, attempt count, questions per page, warning limit, and optional close date/time.

## Set availability and identity

Turn **Accept responses** on when students may open the quiz. Add a close date/time if the quiz has a deadline. Choose the respondent naming field shown in responses. Teachers can rename an individual submission later where the app allows it.

## Configure flow and results

Review Assessment Flow and Results & review options to control how students move through the quiz and what they can see after submitting. Set automatic points rules only after checking the scoring behavior in Preview.

## Add entry questions and reference sheets

Entry questions can collect student details before Start. Mark only necessary fields as required. Reference sheets let students open provided formulas or text during the attempt. Add instructions and completion text so students know what to do before and after the quiz.
