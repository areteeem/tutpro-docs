# Student guide

You can open an assessment through an assignment in Student or by using the join code or link your teacher shares. Use the same TutPro account that joined your provider workspace for assigned work.

## Join an assessment

1. Open the assessment assignment from Student, or visit [Assess](https://assess.tutpro.org) and enter the code from your teacher.
2. If requested, answer the entry questions such as your name or class.
3. Read the instructions and any time limit or attempt information before starting.
4. If reference sheets are enabled, open them while working.

Join codes are case-insensitive. If the code does not work, copy it again and confirm you have the correct link and assessment availability with your teacher.

## Answer questions

Read the task instructions for each question. Depending on the type, you may select one or several options, enter text, match items, categorize choices, or reorder steps. Some questions contain passages, media, hints, or a time limit.

Use **Check answer** when it is available to see feedback or an explanation. Check-answer feedback may be controlled by your teacher. Use **Next** only after you are ready to move on; your response behavior can depend on the assessment flow settings.

## Finish and submit

Review unanswered or flagged work if the assessment allows it. Choose **Submit** and wait for the completion confirmation before closing the tab. If a completion message or result is not shown, reopen the original assignment and check its status before trying again.

Your teacher may release results later. Some quizzes show immediate scores while others hide answers or feedback until review is complete.

## Troubleshooting

- **The assessment is closed:** ask your teacher whether the availability window has ended.
- **The attempt limit is reached:** contact the teacher; do not create another account to bypass the limit.
- **A question did not save:** return to the assignment and check the attempt state before starting again.
- **You cannot see your result:** the teacher may need to finish reviewing or release it.
