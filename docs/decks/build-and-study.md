# Build and edit a deck

Open your deck and choose **Add card**. Enter a prompt and answer; add examples, pronunciation, notes, or media when relevant. Keep each card focused on one recall target.

## Add cards in batches

Use quick-add, tabbed card entry, or bulk import when available. Review the import preview and confirm the front/back mapping before adding cards. Remove duplicates and repair malformed entries before assigning the deck.

## Edit and organize

Open a card to edit its text or media. Reorder cards to create a useful sequence. When a deck has many cards, use the browser/search action to locate a term and inspect its source.

## Share a deck

Use the share action to create a supported share link. Review whether the link allows viewing, copying, or editing before sending it. To assign through Teacher, select the Decks attachment action so the assignment remains linked to the correct deck.
