# Shared decks

## Open and copy a shared deck

1. Open the shared deck link. Check the title and preview the available cards before you use it.
2. Review the actions the owner has allowed. A link may let you view the deck, copy it, or edit it; the owner’s share settings control which actions appear.
3. If **Copy** is available and you want an editable version, choose it and confirm the destination library or workspace when prompted.
4. Open your copy and check the imported cards, formatting, and attribution. Edit your copy as needed; changes to the copy do not change the owner’s original deck.
5. To give students tracked work, assign your deck through Teacher rather than sending only the shared preview link.

Keep the original attribution and review all imported cards before using them with students. A public/shared deck link is different from an assignment sent through Teacher.

For school assignments, open the deck from the Student task so it stays associated with the intended provider and progress record.
