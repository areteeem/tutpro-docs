# Shared decks

Open a shared deck link to preview its title and available cards. The owner’s share settings determine whether you can view, copy, or edit the deck.

If you want your own editable version, use **Copy** when the share page provides that action. Keep the original attribution and review all imported cards before using them with students. A public/shared deck link is different from an assignment sent through Teacher.

For school assignments, open the deck from the Student task so it stays associated with the intended provider and progress record.
