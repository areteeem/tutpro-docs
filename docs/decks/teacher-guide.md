# Teacher assignments

Teachers can manage decks and assign them to a student, group, or course depending on the workspace integration.

## Create an assignment

1. Open **Teacher → Tasks** and start a new assignment, or open the intended student/group record.
2. Choose **Add deck** or **Assign deck** in the assignment attachments.
3. Select the deck. Check its title and content so you attach the intended set of cards.
4. Select the student, group, or course. Confirm the provider workspace and recipient before saving.
5. Set a due date and any study requirements the assignment form offers.
6. Review the student-facing title, recipient, deck, and dates, then save the assignment.
7. Reopen the saved task and check that the deck attachment is present. Students open the work from Student so activity stays linked to the assignment.

Decks assignments remain a distinct attachment type. Confirm the learner is in the correct provider workspace before assigning.

## Review student progress

1. Open the saved assignment in **Teacher → Tasks** or open the assigned student/group record.
2. Select the deck assignment or card progress action to view completion and card-level activity.
3. For a group assignment, review each learner in the group view and note who has not started, is in progress, or has completed the work.
4. Open a learner’s card browser when you need to see which cards need more practice.
5. If the assignment or progress is missing, confirm the student account and provider connection before creating a duplicate.
