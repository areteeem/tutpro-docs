# Teacher assignments

Teachers can manage decks and assign them to a student, group, or course depending on the workspace integration.

## Create an assignment

1. Open **Teacher → Tasks** or the student/group record.
2. Choose **Assign deck** or **Add deck**.
3. Select the deck and assignment target.
4. Set study requirements or due dates where available.
5. Review the generated assignment title and target, then save.

Decks assignments remain a distinct attachment type. Confirm the learner is in the correct provider workspace before assigning.


![Decks navigation with teacher and student areas.](/img/screenshots/decks-navigation.png)

## Review student progress

Open the assignment or student card browser to inspect completion and card-level progress. Use the group view when the same deck is assigned to several learners. Contact the learner if the assignment is missing; confirm the student account and provider connection before creating a duplicate.
