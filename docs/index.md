# TutPro Help

TutPro Help explains how to use Teacher, Student, Decks, Assess, Wordly, and Schools. Use it to follow a workflow from start to finish: prepare work, share or assign it, complete it, and review progress. The guides use the same names as the apps and include step-by-step instructions for common tasks.

## Start here

- [Accounts and sign-in](./accounts)
- [Your first week in Teacher](./teacher/first-week)
- [Join Student](./student/join)
- [Create and assign homework](./teacher/homework-create)
- [Teacher tutorials: assignments, progress, and Copilot](./teacher/tutorials)
- [Complete a Student assignment](./student/tutorial-homework)
- [Decks tutorials](./decks/tutorials)
- [Assess tutorials](./assess/tutorials)

## What you can learn here

| Guide section | Use it to |
| --- | --- |
| Teacher | Create assignments, prepare lessons, review submissions, track learners, and use Copilot. |
| Student | Open homework, submit work, use the learning assistant, and review grades and progress. |
| Decks | Build and share decks, assign study, choose practice modes, and review card progress. |
| Assess | Create and share assessments, use AI to draft questions, review responses, and configure assessment settings. |
| Wordly | Build vocabulary lists, practice words, and export study materials. |
| Schools | Set up school workspaces, manage access, and follow school operations. |

Start with a section if you know the app, or use one of the task guides above if you know what you want to do.
