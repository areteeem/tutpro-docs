# Certificates and issuance

Open **Administration → Certificates** to manage templates and issuance. Templates can be designed for student or teacher recipients, with portrait or landscape layout, background, border, and merge fields.

## Create a certificate template

1. Add a template and enter its name.
2. Choose the recipient type and page orientation.
3. Add text, student/teacher fields, and any approved background artwork.
4. Preview the layout using a sample recipient with a long name.
5. Save the template.


![Certificate template editor and preview.](/img/screenshots/schools-certificates.png)

## Issue a certificate

Select a template and recipient, verify the name and award details, then generate the certificate. Confirm the issued document is recorded in the correct student or staff history. Follow school policy before recording an official issuance.
