# Schools console

The Schools console is a separate, read-only view for a configured school. It displays the assigned school’s schedule and an audit log when the signed-in user’s membership allows it. It does not replace the full Teacher Administration workspace.

## Sign in

Open the Schools URL supplied by your administrator and sign in with the TutPro account that belongs to the configured school. The console checks your school membership before loading any data.

If access is unavailable, check that you are using the right account and that your school membership is active. A missing membership, suspended access, or incomplete console configuration has a specific status message on screen.

## Review schedule

Use the schedule table to review start time, duration, status, and class. Choose **Refresh** to load current data and **Load more** when additional pages are available.

## Review audit activity

The Audit log appears only when the role has access. Review the event time, activity, and summary. If the log is hidden, ask an administrator to confirm your assigned role.
