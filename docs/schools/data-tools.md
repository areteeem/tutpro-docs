# Data tools

Use school data tools to review or export records you are authorized to access. Open **Administration → Data**.

## Export a working copy

1. Select the data area and date or status filters offered by the page.
2. Review the scope before exporting, especially when the school has multiple campuses.
3. Save the export in an approved school location and restrict access to staff who need it.
4. Treat exported files as sensitive records and remove local copies when no longer needed.

Exports do not change the source records. For a history of administrative changes, see the [Audit log](./audit-log).
