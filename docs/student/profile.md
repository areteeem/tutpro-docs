# Profile

Open **Profile** from the navigation or account button. Review your name, level, time zone, guardian/contact details, and provider workspace information that the app displays.

Edit only fields that have an edit control. Save and wait for the sync confirmation before closing the app. If the provider owns a field, contact them to request a correction.
