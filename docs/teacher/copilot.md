# Copilot and lesson planning

Open **Copilot** from the workspace navigation or the lesson planning action. When launched from a lesson or student context, the assistant may use the details visible in that workflow to make a relevant draft.

## Generate a teaching draft

1. Choose the current lesson or student context when available.
2. Describe the intended output, such as a lesson outline, explanation, homework draft, or practice questions.
3. Review the draft for correctness, student level, curriculum fit, and tone.
4. Edit the content, then insert or save it only in the intended lesson or task.

Generated material is a draft. Check every answer key and factual claim before sharing. Avoid putting sensitive personal information into prompts unless your organization has approved that use.
