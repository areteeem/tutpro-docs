# Import, export, and recovery

Use the workspace data tools to import supported spreadsheets or export a backup. Import and export availability depends on your role and selected workspace.

## Import records

1. Select the intended workspace and open the import tool.
2. Choose a supported file and review the detected sheets and field mapping.
3. Resolve missing required fields and inspect the preview for duplicates or incorrect ownership.
4. Confirm the import only after reviewing the record count and target.
5. Reopen a sample student, lesson, and task to confirm the imported data.


![Workspace-aware data import preview.](/img/screenshots/teacher-data-import.png)

## Export a backup

Choose the intended data scope, then export. Keep the file in private storage; it can contain student and financial records. Use an encrypted location and restrict access to people authorized for the workspace.


![Backup, import, and export tools.](/img/screenshots/teacher-backup-tools.png)

## Restore or migrate

Follow the import tool’s supported restore format. Do not restore a personal backup into a school workspace unless the source, ownership, and sharing scope have been reviewed.
