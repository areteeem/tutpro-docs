# Feed and announcements

Open **Feed** to review or publish posts. Check the active workspace and audience before writing; school-wide announcements may require a school role.

## Create a post

Choose the create action, write a concise title and message, and format it using the available editor. Select the intended audience and review the preview. Avoid posting personal student details to a broad audience.

## Publish and follow up

Publish when the content and audience are correct. Open the post later to review responses and engagement. Edit or archive outdated information using the available controls.

For academic events, announcements, and audit history managed by school administrators, use **Administration → Communications** when that section is available.
