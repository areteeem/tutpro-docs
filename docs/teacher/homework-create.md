# Create and assign homework

Open **Tasks** and choose **Assign task**, or start from a student or lesson. Confirm the intended student or group before writing the task.

If you start from a student or lesson, check that the selected workspace and learner remain correct when the task editor opens. Starting from a lesson can carry lesson context into the assignment; remove or replace any detail that does not apply to the homework.

## Create a task

1. Enter a short title and student-facing instructions.
2. Select the student, group, or eligible recipients.
3. Set the assigned date and due date. Use a due-date shortcut only after checking the resulting date.
4. Add links, files, or images as needed. Save a new task before uploading images if the editor asks you to.
5. Add task items and points when you want TutPro to calculate a maximum grade.
6. Choose the submission method available for the task. Decks work is a dedicated attachment type; use **Add deck** instead of pasting a deck as a normal link.
7. Preview the student-facing task and save.

Before saving, read the task once as a student: check that the first action is clear, all linked files open, the due date is later than the assigned date, and the requested submission type is enabled. If the task has a score, make sure every point value and the displayed maximum are intentional.

## Link a saved resource

Use **Library** to insert a reusable homework template or lesson material, then adapt the copy for this student and due date. A template is a starting point; check that links, instructions, and attachments are current before assigning.

## Create a recurring homework sequence

When the recurring option is available, choose the number of assignments and the interval. Review the generated due dates and titles before saving the sequence.

## After assigning

Open the saved task and confirm its target, status, due date, and attachment. The student sees it after the update syncs to their workspace.

Then open the student task list or assignment detail and verify that the title and due date match. If the task is missing, confirm workspace, student assignment, and sync status before creating a second copy. Use [Edit homework](./homework-edit) for corrections so the original assignment record remains the one students follow.
