# Homework library

Open **Library → Homework** to save reusable instructions, links, and task structures. A library item is a template; assigning it creates or links work for a particular learner.

## Create a homework template

1. Choose **Add** and give the template a clear name.
2. Add student-facing instructions, links, task items, and any reusable files.
3. Save the template and open its preview.
4. Remove dates or student-specific wording that should not carry over to every use.


![Create a reusable homework template.](/img/screenshots/teacher-homework-template-create.png)

## Assign from the library

Open the student task flow, select the library item, then choose the target student or group. Set the assigned and due dates and check every attachment. Save the task, then confirm it appears in the Tasks list.

![Link lessons and tasks to a homework template.](/img/screenshots/teacher-homework-template-links.png)

## Keep shared materials current

When a template changes, review active assignments separately. Updating a library source does not necessarily rewrite tasks already sent to students.
