# Lesson library

Open **Library → Lessons** to keep reusable lesson plans and teaching materials. Use a clear title and organize the content so you can find it while preparing a session.

## Add a lesson resource

1. Choose **Add to library** and select a lesson/resource type.
2. Enter a title and structure the plan with steps, links, notes, and any supporting materials.
3. Save and review the preview for formatting and broken links.


![Create a lesson plan with level and topic details.](/img/screenshots/teacher-lesson-create.png)
![Lesson plan editor with activities and AI recommendation controls.](/img/screenshots/teacher-lesson-editor.png)

## Use a resource in a lesson

Open the schedule entry and attach a library item from its learning-material controls. Adapt student-specific details in the lesson or homework draft. Check that the attached material is visible from the lesson before starting class.

## Organize and find items

Use search, filters, and grid/list view controls to locate an item. When bulk actions are available, select the intended rows before exporting, copying, assigning, or removing them.
