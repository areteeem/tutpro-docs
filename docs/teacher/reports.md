# Reports

Open **Reports** and select a report type or preset. Choose its date range and workspace scope, then review the preview before exporting.

## Prepare a report

1. Select the report type and date range.
2. Apply available student, teacher, campus, or status filters.
3. Check the displayed source counts and totals.
4. Export to a supported format or use print/PDF where available.
5. Reopen the source records if a total looks unexpected.

The report reflects the records visible to your role and the selected filters. For finance, reconcile it with the payment/expense ledgers and your external accounting source before relying on it for bookkeeping.
