# Exercises

Open **Exercises** from the top bar, the mobile bottom navigation, or **Ctrl/⌘+Shift+X**. Choose a source document or practice across your vocabulary, then select a mode.

## Available modes

| Mode | How it works |
| --- | --- |
| Flashcard Review | Reveal each answer and rate recall as Again, Hard, Good, or Easy. Ratings schedule future review. |
| Type Translation | Type the translation, use a hint if needed, and retry missed terms. |
| Type the Word | See a meaning and type the original word. |
| Multiple Choice | Choose a translation and get feedback as you go. |
| Fill in the Blanks | Reveal missing words in context. |
| Context Clues | Use the example sentence to identify a missing word. |
| Word Bank | Match words from the bank to their meanings. |
| Match Pairs | Pair word cards with their translations. |
| Word Scramble | Rebuild the source word from scrambled letters. |
| Fortune Wheel | Spin to select a vocabulary target; options can narrow the practice pool. |

The mode’s on-screen instructions describe its controls. Flashcard review updates the spaced-review schedule. Other exercise scores are session feedback to help you decide what to revisit.

## A useful review routine

1. Start with Flashcard Review to handle words that are due.
2. Rate each answer honestly. Use **Again** when you could not recall it without help.
3. Switch to Type Translation or Type the Word to practice active recall.
4. Use Context Clues or Fill in the Blanks to connect a term to its example sentence.
5. Return to the Vocabulary browser to fix unclear translations or add missing context.
