# Exercises

Open **Exercises** from a document or the vocabulary browser. Select a mode and follow the prompt. Available modes include flashcards, type-in, reverse type-in, scramble, fill-in-the-blanks, match pairs, and fortune wheel.

For a type-in activity, enter your answer and choose **Check**. Review the score and retry missed terms where the mode supports it. Match-pairs and wheel modes may use a separate interaction; follow their on-screen instructions.

Exercise grades are a practice aid. Return to the source document to edit an unclear word or translation.
