# Practice and export

Open an exercise from the document or vocabulary browser. Choose a mode, complete the prompts, check your work, and review terms you missed. Use the home page’s mastery and weekly summaries to choose the next topic.

## Export your work

Open **Export** or use **Ctrl/⌘+Shift+E** where supported. Select a document or vocabulary list and choose a format. Preview the selected content and verify the exported file before sharing.

## Back up local data

Wordly currently saves content to the browser profile rather than a shared TutPro database. Export documents and vocabulary regularly, especially before clearing browser data or moving devices. Keep the backup private and remember that it is a snapshot.
