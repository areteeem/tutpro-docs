# Practice and export

Start a practice session from **Exercises** or the full Vocabulary browser. Select a source document where available, choose a mode, and follow its on-screen prompts. Flashcard Review is due-first when review cards are ready; use the four ratings to update the spaced-review schedule. Other modes provide practice and session feedback.

For the full walkthrough, see [practice with flashcards](./tutorials#4-practice-with-flashcards).

## Export vocabulary or a document

1. Open **Export** from the top bar or press **Ctrl/⌘+Shift+E**.
2. Choose a scope: all vocabulary, one folder, one tag, a document, or selected words.
3. Choose CSV, plain text, Markdown table, Anki text, Vocabulary PDF, Document PDF, or Document + Words PDF.
4. Set the available options, such as context, tags, date, student name, or document layout.
5. Choose **Export**. For PDF formats, use the browser’s print dialog to save a PDF or print a copy.
6. Open the result and check the content before using or sharing it.

The full browser lets you export the currently filtered entries as CSV. The Vocabulary panel also offers quick copy/export actions for its visible list.

## Back up local work

Wordly keeps documents and folders in browser storage on this device. Export important vocabulary and documents before clearing site data or changing browsers. Keep the backup somewhere separate from the browser profile and verify that the exported file opens correctly.
