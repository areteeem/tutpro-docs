# Settings, templates, and shortcuts

Open **Settings** from the top bar, mobile navigation, or **Ctrl/⌘+,**. Changes are saved in this browser profile.

## Appearance and editor

Choose light, dark, or neutral theme; adjust accent and highlight colors, editor font size, and compact or comfortable density. Editor settings include the vocabulary panel’s default view, language detection, and auto-save behavior.

## Vocabulary capture and translation

Set the daily word goal and choose whether text selection opens a translation reveal. Configure the popup delay, translation source and target languages, and whether a suggested translation is accepted automatically. You can also require confirmation and choose the duplicate-check scope. Review machine-suggested translations before using them.

Translation suggestions use external services when requested and need an internet connection. If no suggestion appears, enter the translation manually.

## Templates and keyboard shortcuts

Open the command palette with **Ctrl/⌘+K**. With a document open, choose **Save as Template**; later, choose **New from: _template name_** to make a copy. The keyboard-shortcuts panel opens with **?** when you are not typing in an input or the editor.

Common commands:

- **Ctrl/⌘+N:** New document
- **Ctrl/⌘+K:** Command palette
- **Ctrl/⌘+Shift+B:** Full Vocabulary browser
- **Ctrl/⌘+Shift+X:** Exercises
- **Ctrl/⌘+Shift+E:** Export
- **Ctrl/⌘+,**: Settings

On macOS, use **⌘**; on Windows and Linux, use **Ctrl**. If your browser or operating system intercepts a shortcut, use the visible toolbar control.
