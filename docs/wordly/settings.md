# Settings, templates, and shortcuts

Open **Settings** using the visible controls or **Ctrl/⌘+,** where supported. Review appearance, editor, vocabulary, highlight popup, translation, export, and data preferences.

Use a template to start a document with a repeatable structure. Open **Ctrl/⌘+K** for the command palette and the keyboard-shortcuts panel to find available actions. If a shortcut is intercepted by the browser or operating system, use the menu action instead.
