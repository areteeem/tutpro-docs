# Vocabulary browser

Open the vocabulary browser using its toolbar action or **Ctrl/⌘+Shift+B** where your browser supports the shortcut. It shows words in a table or card view.

Search the list, filter or sort entries, and open an item to edit its word, translation, tags, or notes. Star a term to find it during later review. Use **Jump to source** to return to the document where the term was added.

The browser can copy a table or list and export CSV. Check the selected rows and columns before copying or exporting. A spreadsheet export may not preserve document formatting.
